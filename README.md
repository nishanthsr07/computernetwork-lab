# ComputerNetworkLab

ComputerNetworkLab contains practical networking experiments, code, and simulations. It covers socket programming, protocol analysis, IP addressing, subnetting, and client-server models using tools like Cisco Packet Tracer, Wireshark, and Python for hands-on learning.

## Contents
- Socket Programming (TCP/UDP)
- Protocol Analysis with Wireshark
- IP Addressing & Subnetting
- Client-Server Architecture
- Network Topology Design

## Tools Used
- Cisco Packet Tracer
- Wireshark
- Python Networking Libraries
